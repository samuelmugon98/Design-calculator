# PIP Design Estimator

Four-step calculator for estimating design hours: pick deliverables, set quantities and design QA rounds, tick project conditions, and get total hours, working days and Paymo alert thresholds.

Open `index.html` in a browser. No build step or dependencies.

The hour values and formulas come from the team's spreadsheet `Estimaciones_Tiempo_Diseno_PIP.xlsx`.
